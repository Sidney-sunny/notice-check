# 可检查 JSON 结构
顶层：summary 字符串、sources 数组、items 数组、priorities 字符串数组。
sources 每项：id、name、publisher、date、locator、coverage、text（实际读到的文字，非猜测）。
items 每项：field、value、scope、status、evidence 数组。evidence 每项含 source、quote，quote 应为对应 source.text 的逐字短摘录。缺失项也需引用读取范围中的相关文字；整页不可读时可留空证据。
日期必须原样保留在 value；可加“年份未注明”等说明，不按当前时间补年。
可选 changes 数组：field、old、new、source、quote。新旧值都要能由相应材料支持。
脚本校验不替代语义复核，无法自动判断发布关系与资格成立。
