一、大赛简介
为秉承“以赛促学、以赛促教、以赛促就业”的宗旨，提升我校学生数智创新与AI应用开发实践能力，现组织开展第九届传智杯全国大学生数智创新与AI应用大赛开发类赛事校内选拔赛。本届大赛聚焦人工智能应用与创新，推动传统赛项深度融入AI元素，开发类赛事涵盖AI Web网页开发、AI云计算大数据开发、AIoT嵌入式系统创新、AI赋能智能测试等方向。校内选拔赛是晋级省赛（复赛）的重要通道，欢迎全校同学积极组队参赛。现将有关事项通知如下：

GitHub/Gitee 代码仓库（须 Public 或提供评审权限）＋README＋环境配置说明＋完整 Git 提交历史；另提交 5—8 分钟演示视频（MP4，≥1080p，普通话讲解）、技术文档（PDF，不超过30页）及可公网访问的在线演示地址。
AIoT嵌入式系统创新大赛（团队赛）
提交 ZIP 作品包（不超过 200MB，命名“AIoT嵌入式系统创新大赛-作品名称”），内含作品介绍文档、实物照片及原理图等；讲解视频上传至 B站、抖音等平台，仅提交视频链接；鼓励提供 BOM 表及开源代码仓库链接。
AI WEB网页开发挑战赛（团队赛）
GitHub/Gitee 代码仓库（须 Public 或提供评审权限）＋README＋环境配置说明＋完整 Git 提交历史；另提交 5—8 分钟演示视频（MP4，≥1080p，普通话讲解）及技术文档（PDF，不超过30页）；在线演示为可选加分项。
AI赋能·智能测试创新挑战赛（团队赛）
提交 ZIP 作品包（不超过 200MB，命名“AI智能体测试挑战赛-作品名称”），内含作品介绍文档、测试用例及执行记录等；讲解视频上传至 B站、抖音等平台，仅提交视频链接（建议 5—10 分钟）；鼓励开源测试工具代码。
注意事项：
1.采用 GitHub/Gitee 提交的赛道，代码仓库须设为 Public 或提供评审访问权限，并保留完整、细粒度的 Git 提交历史（禁止一次性提交即包含全部功能，每次提交应对应一次与 AI 的核心对话或一个功能模块的落地），官网将重点核查作品原创性与开发过程可复现性。
2.ZIP 类赛道压缩包命名须按官方指定格式，大小不超过 200MB。
3.视频
需要上传公开平台的赛道
统一上传至 B站、抖音等可公开访问的视频平台，提交时仅提供视频链接，无需提交视频文件。
4.
校赛作品提交与省赛（官网）提交采用同一标准，具体以大赛官网各赛道详情为准。

（二）晋级规则
校赛一、二、三等奖获得者晋级省赛；未晋级选手无法参与省赛。
（三）名额资助
学院根据最终评审结果资助一定名额的项目进入省赛，其他晋级省赛的项目可自费报名参加省赛。
